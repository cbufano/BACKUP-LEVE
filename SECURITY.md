# Segurança

## Como relatar uma falha

Não abra uma issue pública para falha de segurança ou para erro que faz o usuário perder arquivos.

1. Abra a aba **Security** do repositório no GitHub.
2. Clique em **Report a vulnerability**.
3. Descreva o problema e os passos para reproduzir.

Os mantenedores respondem em até 7 dias.

## Versões com suporte

O projeto ainda não tem versão pública. Só a branch `main` recebe correções.
