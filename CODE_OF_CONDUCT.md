# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## Resumo

- Trate todas as pessoas com respeito.
- Critique o código, não a pessoa.
- Não use linguagem ofensiva, assédio ou ataque pessoal.
- Aceite a decisão dos mantenedores sobre o que entra no projeto.

## Como relatar um problema

Use o relato privado do GitHub (aba **Security** do repositório) ou entre em contato com os mantenedores pelo perfil do GitHub.
Todo relato é tratado com sigilo.
